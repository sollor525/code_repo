## 🚀 使用示例

### 快速开始
```bash
# 1. 构建项目
cd examples/http_scanner
./build.sh

# 2. 生成测试数据
cd tools
python3 generate_test_pcap.py test_attacks.pcap

# 3. 运行检测
cd build
./http_scanner --rules ../rules --pcap ../tools/test_attacks.pcap
```
