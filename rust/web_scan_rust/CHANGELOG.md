## [未发布]

### 新增
- 🎯 **PCRE字段支持**: 完整实现PCRE（Perl Compatible Regular Expressions）字段处理
- 🚀 **三层匹配架构**: 实现Fast Pattern → Normal Content → Regex Fallback的智能分层处理
- ⚙️ **完整修饰符系统**: 支持nocase、startswith、endswith、distance、depth、offset、within修饰符
- 🔧 **自动兼容性检测**: 智能检测PCRE模式与Hyperscan的兼容性
- 📚 **完整文档**: 添加PCRE支持文档和规则格式更新
- 🧪 **全面测试**: 24个PCRE专项测试，覆盖兼容性、功能和边缘情况

### 优化
- ⚡ **Hyperscan默认集成**: 移除Hyperscan enable开关，使其成为默认模式
- 🔄 **智能模式转换**: 自动将复杂PCRE模式转换为Hyperscan兼容格式
- 🏗️ **Arc共享数据库**: 使用Arc实现线程安全的数据库共享
- 🎛️ **零拷贝优化**: 进一步优化内存使用和数据复制

### 修复
- 🐛 修复PCRE解析中的模式边界处理bug
- 🔧 修复修饰符转换和标志计算问题
- 🛡️ 增强错误处理和边界情况处理
- 📝 完善文档和代码注释

## [0.1.0] - 2024-12-01

### 新增
- 🎯 **完整功能实现**: Suricata/Snort兼容的Web扫描检测引擎
- ⚡ **Fast Pattern优化**: 实现Suricata兼容的双数据库架构优化
- 🔄 **多Pattern支持**: 支持单条规则包含多个content模式和HTTP位置验证
- 📦 **分段数据包处理**: 完整的TCP流重组和HTTP协议边界检测
- 🚀 **高性能设计**: 零拷贝、原子操作、智能缓存等性能优化
- 🛡️ **内存安全**: Rust内存安全保证，无内存泄漏风险
- 🔗 **FFI接口**: 完整的C语言API，与VPP/IPS无缝集成
- 📊 **统计监控**: 实时性能监控和流量统计

### 支持的功能
- HTTP/HTTPS/HTTP2智能协议识别
- JSON、TOML、Hyperscan/Snort规则格式支持
- Intel Hyperscan高性能匹配引擎（默认）
- 线程安全的并发处理
- Suricata兼容的Fast pattern匹配算法

### 测试
- ✅ **单元测试**: 39/39 通过 (100%)
- ✅ **集成测试**: 26/26 通过 (100%)
- ✅ **总测试**: 65/65 通过 (100%)

## 版本说明

### 版本号规则
- **主版本号**: 不兼容的API修改
- **次版本号**: 向下兼容的功能性新增
- **修订号**: 向下兼容的问题修正

### 生命周期
- **主版本**: 长期支持，向后兼容的更新
- **次版本**: 6个月支持，功能增强
- **修订版**: 3个月支持，bug修复和安全更新

### 发布周期
- **主版本**: 按需发布，主要功能变更
- **次版本**: 每月发布，新功能集成
- **修订版**: 根据需要发布，紧急修复
