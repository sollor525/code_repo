使用说明

范围语法

  • 固定: 10.0.0.1 / 80
  • 区间: 10.0.0.1-10.0.0.100 / 80-443
  • 随机: random（每会话随机取值）

协议

  • TCP: 仅 SYN / 三次握手 / +四次挥手 / +RST
  • HTTP: 默认 GET，或自定义请求/响应内容
  • ICMP / UDP: echo 与 UDP 收发（IPv4 / IPv6）
  • FTP / SSH / MySQL: 代表性应用层报文
