使用说明

范围语法

  • 固定: 10.0.0.1 / 80
  • 区间: 10.0.0.1-10.0.0.100 / 80-443
  • 随机: random（在每个会话随机取值）

生成内容

  • 每个会话包含完整 TCP 三次握手
  • 勾选 HTTP 时追加请求 / 响应报文
  • 可叠加单层 VLAN 或 QinQ 双层标签
  • 导出标准 Ethernet 链路层 PCAP
