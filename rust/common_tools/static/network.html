使用说明

IP 地址格式

  • IPv4: 192.168.1.1
  • IPv6: 2001:db8::1
  • 十六进制: 0xC0A80101 (IPv4网络序)

端口格式

  • 十进制: 8080
  • 十六进制: 0x1F90
  • 范围: 0-65535

整数格式

  • 十进制: 123456789
  • 十六进制: 0x075BCD15
  • 支持: 32位和64位整数

快捷操作

Enter 在输入框中按回车执行转换
Esc 清空当前输入框内容
Ctrl + Home 返回主页

快速示例

示例1: IP地址 192.168.1.1 → 网络序 0xC0A80101
示例2: 端口 8080 → 网络序 0x1F90 (8080)
示例3: 整数 123456789 → 网络序 0x075BCD15 (123456789)
