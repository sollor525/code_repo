Base64 速查

字母表差异

  • 标准: 第 62/63 号字符为 + 与 /
  • URL 安全: 换成 - 与 _，可直接放进 URL / 文件名
  • 填充: 补 = 使长度为 4 的倍数；JWT 等场景常省略
  • 换行: MIME 邮件正文通常每 76 字符换行
  • 解码侧两种字母表通吃，缺失填充也能还原

示例

  • foobar → Zm9vYmFy
  • f → Zg==（不填充则为 Zg）
  • 字节 fb ff fe → 标准 +//+ / URL 安全 -__-
  • 解码出的二进制会以 偏移 hex |ASCII| 转储展示
