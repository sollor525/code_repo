📖 使用说明

📝 支持的协议

  • 以太网帧: MAC地址、EtherType
  • IPv4: 源/目标IP、协议类型
  • TCP: 源/目标端口
  • UDP: 源/目标端口
  • ICMP: 类型、代码

🎯 分析功能

  • 自动识别数据包类型
  • 解析网络层头部信息
  • 提取传输层端口信息
  • 显示数据包长度
  • 导出标准PCAP格式

📚 示例数据格式

TCP数据包示例：

08002712345608002712345608000450000283c7c4000400643c2c0a80101c0a801c8

包含的协议信息：

  • 以太网头部：MAC地址、EtherType (0x0800 = IPv4)
  • IPv4头部：源IP、目标IP、协议 (6 = TCP)
  • TCP头部：源端口、目标端口
