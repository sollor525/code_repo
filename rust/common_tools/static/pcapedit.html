CH · PCAP — rewrite addresses

PCAP 修改

按五元组（源 IP / 目的 IP / 源端口 / 目的端口 / 协议，各字段可为 any）匹配 TCP/UDP 报文，把其源/目的 IP 与源/目的 MAC 改写为指定值。改写按「客户端→服务端」方向理解，反向（stoc）报文自动对调，并重算 IP 与 TCP/UDP 校验和。

按五元组改写地址

五元组过滤（留空 = any）
五元组按 ctos 方向书写。匹配时同时考虑反向（源/目的对调）的 stoc 报文。仅 TCP/UDP 报文会被改写。
改写目标（留空 = 保持）
新源 = 客户端的新地址，新目的 = 服务端的新地址。stoc 报文里客户端出现在目的字段，工具会自动把「新源」写到其目的、「新目的」写到其源。
保存（仅「修改并保存」用到）
「预览」只统计命中与改写前后样例，不写文件；确认无误后再「修改并保存」。

结果

选择 pcap 文件并设置条件后点击「预览」。
说明与示例

用法要点

匹配规则

  • 五元组任一字段留空或填 any 即通配
  • 正向命中记为 ctos，源/目的对调命中记为 stoc
  • 仅 TCP / UDP 报文参与改写；其余原样保留
  • 先用「预览」确认命中数与改写前后样例，再「修改并保存」

改写与校验和

  • MAC 仅换以太网首部，不影响校验和
  • 改 IP 会自动重算 IPv4 头与 TCP/UDP 校验和
  • UDP 原校验和为 0（未启用）时保持 0
  • 对 IPv4 报文只能填 IPv4 新地址，IPv6 同理
  • 仅支持以太网链路、传统 pcap（非 pcapng）
