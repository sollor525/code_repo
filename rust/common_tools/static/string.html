字符串转义序列转换

八进制（\000）与 Unicode（\u0000）转义序列双向互转，可自动检测输入格式。

字符串格式转换

点击"转换"按钮查看结果
说明与示例

使用示例

八进制转 Unicode

输入格式: \000, \242, \002 等
4\000\000\000\n5.0.54\000

Unicode 转 八进制

输入格式: \u0000, \u00a2, \u0002 等
4\u0000\u0000\u0000\n5.0.54\u0000

复杂示例

包含多种转义序列:
4\000\000\000\n5.0.54\000^\000\000\000>~$4uth,\000,\242!\002

使用说明

转换类型

  • 自动检测: 智能识别输入格式并自动转换
  • 八进制到Unicode: 将 \000 格式转为 \u0000
  • Unicode到八进制: 将 \u0000 格式转为 \000
  • 支持往返转换，确保数据完整性

格式规范

  • 八进制格式: 反斜杠 + 3位八进制数字 (\000-\377)
  • Unicode格式: 反斜杠 + u + 4位十六进制数字
  • 支持 0-255 范围内的字符编码转换
  • 保留非转义序列字符原样输出

应用场景

  • 调试输出格式化
  • 字符串编码转换
  • 日志文件处理
  • 协议数据分析
