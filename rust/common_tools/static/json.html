说明与示例

JSONPath 简版速查

支持的语法

  • $ 根节点（可省略）
  • .name / ["na me"] 取字段（含特殊字符用中括号）
  • [0] 取下标，[-1] 取最后一个
  • .* / [*] 通配当前层全部成员
  • ..name 递归下降找所有同名字段，..* 取所有后代
  • 暂不支持过滤表达式 [?(...)] 与切片 [a:b]

示例

  • $.store.book[0].title 第一本书的标题
  • $.store.book[*].title 所有书的标题
  • $..price 文档中所有 price
  • 格式化保留原始键顺序；勾选「排序键」才递归按字典序排列
  • 大整数与长小数原样保留，不会被浮点精度截断
