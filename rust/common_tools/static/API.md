# 通用工具集 API 文档

## 🌐 Web 界面访问

启动服务后，可以通过以下地址访问：

- **主页**: http://localhost:3030
- **网络序转换**: http://localhost:3030/network.html
- **报文分析**: http://localhost:3030/packet.html
- **正则匹配**: http://localhost:3030/regex.html
- **API 文档**: http://localhost:3030/ (JSON 格式)

## 📱 功能特性

### 🏠 主页 (index.html)
- 项目介绍和特性展示
- 快速导航到各功能页面
- API 使用示例
- 技术栈说明
- 部署指南

### 🌐 网络序转换 (network.html)
- **IP地址转换**: IPv4/IPv6 与十六进制格式互转
- **端口转换**: 主机序与网络序互转
- **整数转换**: 32位/64位整数转换
- **实时转换**: 输入即可看到结果
- **格式支持**: 十进制、十六进制格式

### 📦 报文分析 (packet.html)
- **Hex数据解析**: 支持多种格式输入
- **协议分析**: 以太网、IP、TCP/UDP、ICMP
- **示例数据**: 内置TCP、UDP、ICMP示例
- **PCAP导出**: 一键导出标准PCAP文件
- **拖拽支持**: 支持拖拽文本文件

### 🔍 正则匹配 (regex.html)
- **实时匹配**: 输入即可看到匹配结果
- **高级选项**: 大小写敏感、多行模式、点号匹配所有字符
- **内置示例**: 邮箱、电话、URL、IP地址常用正则
- **捕获组显示**: 显示所有捕获组和位置信息
- **一键使用**: 快速使用常用正则表达式

## 🚀 使用指南

### 快速开始
1. 启动服务：`cargo run -- --host 0.0.0.0 --port 3030`
2. 浏览器访问：http://localhost:3030
3. 选择需要的功能页面
4. 输入数据，查看结果

### 高级功能
- **API调用**: 可以直接调用RESTful API
- **批量处理**: 支持大量数据处理
- **数据导出**: 支持PCAP文件导出
