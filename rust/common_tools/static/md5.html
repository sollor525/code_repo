MD5 哈希计算

对文本或文件计算 MD5 摘要，用于数据校验与文件完整性验证。

文本 MD5 计算

点击"计算 MD5"按钮查看结果

文件 MD5 计算

选择文件后点击"计算文件 MD5"按钮
说明

使用说明

文本计算

  • 支持任意文本内容，包括中文、英文、数字等
  • 实时计算，输入后即可查看结果
  • 支持多行文本和特殊字符
  • 结果可一键复制到剪贴板

文件计算

  • 支持任意格式和大小的文件
  • 显示文件大小和基本信息
  • 适用于文件完整性校验
  • 支持拖拽上传文件

应用场景

  • 密码哈希存储
  • 文件完整性验证
  • 数据校验和比较
  • 开发调试和测试
