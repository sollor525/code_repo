使用说明

匹配选项

  • 区分大小写: a ≠ A
  • 多行模式: ^$ 匹配行首行尾
  • 点号匹配所有: . 匹配换行符

常用语法

  • \b: 单词边界
  • \d: 数字 (0-9)
  • \w: 字母数字下划线
  • [a-z]: 字符范围
  • (.*?): 非贪婪匹配

常用正则表达式

邮箱地址: \b[A-Za-z0-9._%+-]+@[A-Za-z0-9.-]+\.[A-Z|a-z]{2,}\b
电话号码: \b\d{3}-\d{3}-\d{4}\b
URL地址: https?://[^\s]+
IPv4地址: \b(?:\d{1,3}\.){3}\d{1,3}\b

快捷键

Windows/Linux

  • Ctrl + Enter - 执行匹配
  • Ctrl + L - 清空所有

Mac

  • Cmd + Enter - 执行匹配
  • Cmd + L - 清空所有
